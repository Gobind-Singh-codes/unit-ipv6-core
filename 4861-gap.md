## 2. Design notes

- **Role is evidenced, not assumed.** DUT membership in `ff02::2` (all-routers,
  both interfaces) proves router role; `--dut-role router` records it. A host
  DUT would take NOT_APPLICABLE on ND-01 instead.
- **ND-01 runs three RS variants** (global+SLL, link-local+SLL, global w/o SLL)
  because the original single shape elicited nothing; variant (a) decided it.
  Per-variant TX is proven (`tx_seen` is source-aware).
- **ND-02 route snapshots normalize `expires` countdowns** — their ticking is
  not state change. Bogus-marker appearance would be FAIL; unrelated churn is
  INCONCLUSIVE; identical is PASS.
- **ND-03 names the interface** (`--non-adv-iface`, validated shape) and audits
  `forwarding` (recorded, never condemning), `send_ra` (absent here, neutral),
  and radvd attachment (self-match excluded — the probe's own command line can
  never count). Contradiction refuses loudly unless `--force` (recorded).
- **Scapy trap documented:** `PrefixInfo(prefix=…)` treats a bare
  `2001:db8:dead` (no `::`) as a hostname and attempts DNS (`gaierror`); the
  constant is full-literal with a warning comment, and the unit test consumes
  it verbatim so they cannot drift apart.
