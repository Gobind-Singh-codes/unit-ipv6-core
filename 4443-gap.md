## 2. Design notes (why these verdicts hold)

- **Suppression controls are UDP-based.** The DUT never emits Parameter Problem for
  unknown options (see 8200 IP-02/04), so the original unknown-opt control could
  never succeed. UDP-to-closed-port (Port Unreachable) is the primary trigger
  with unknown-opt fallback; whichever fires is recorded in `control`.
- **Non-DUT destinations use next-hop L2** (`l2_next_hop: fd:33:33:33::1`).
  Resolving the final destination's MAC is impossible for anycast/TEST-NET
  space; earlier runs ERRORed on exactly this before the fix.
- **`02c` fallback is one packet**, recorded as `fallback: hlim=1 expiry probe`.
  It forces the DUT (first hop) to originate Time Exceeded, exercising the same
  source rule the silent echo could not.
- **Anycast is operator-attested** (`anycast_target` + `anycast_proof` recorded,
  never executed or inferred). The subnet-router anycast used here is required
  on every router, independently verifiable via `/proc/net/anycast6`.

## 3. Gaps: none open

No INCONCLUSIVE, no ERROR, no NOT_APPLICABLE. The only standing caveat: `02c`
depends on the DUT being the first hop (Hop Limit 1 expiry); on a multi-hop
test path the fallback would stay silent and the verdict correctly reverts to
INCONCLUSIVE.
